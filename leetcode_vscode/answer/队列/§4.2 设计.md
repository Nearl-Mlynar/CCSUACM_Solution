### 2026/4/21

## [3508.设计路由器](https://leetcode.cn/problems/implement-router/description/)

### 2026/4/21

方法一：

一个超级**bt**的题目，巨容易 $TLE$，使用一个 `set` 去重维护，使用一个 `unodered_map<int, deque<int>>`来维护键值信息，然后在使用一个队列来维护进入出去顺序。

时间复杂度：$O(nlogn)$，空间复杂度：$O(n)$。

方法二：

使用GCC高级库扩展，使用红黑树模板来快速获取时间在$[startTime, endTime]$，时间复杂度为：$O(logn)$。

```cpp
#include <ext/pb_ds/assoc_container.hpp> // PBDS 容器
#include <ext/pb_ds/tree_policy.hpp>     // PBDS 树策略

----
#include <std/extc++.h> // 或者使用GCC高级库万能头文件
using namespace __gnu_pbds; // 必须加这个命名空间
```

#### 1. PBDS的初始化命名

```
typedef tree<
    pair<int, int>,                // 1. Key (关键字类型)
    null_type,                     // 2. Mapped (映射类型)
    less<pair<int, int>>,          // 3. Comparison (比较方式)
    rb_tree_tag,                   // 4. Tag (树的类型)
    tree_order_statistics_node_update // 5. Policy (更新策略)
> ordered_set;
```

1. `pair<int, int>` (Key)

    - 这决定了集合中存储的数据类型。

    - `std::set` 和 `pb_ds::tree` 默认都是**去重**的。使用 `{timestamp, source}` 作为 Key，可以确保即使时间相同，只要来源不同，也是不同的元素，从而模拟出 `multiset` 的效果。

2. `null_type` (Mapped)

    - 如果你想把它当 `set` 用，就写 `null_type`。

    - 如果你想把它当 `map` 用，这里写 Value 的类型。

    - *注意：在旧版本的编译器中，这里可能需要写 `low_probe_fn` 或 `mapped_type`，但在现代 GCC 中统一用 `null_type`。*

3. `less<pair<int, int>>` (Comparison)

    - 定义排序规则。`less` 表示从小到大。

    - 如果你想从大到小，可以用 `greater<...>`。

4. `rb_tree_tag` (Tag)

    - 指定底层数据结构。

    - `rb_tree_tag` 是**红黑树**，性能最稳定，也是最常用的。

    - 此外还有 `splay_tree_tag`（伸展树）和 `ov_tree_tag`（有序向量树），但在算法竞赛中，红黑树几乎是唯一选择。

5. `tree_order_statistics_node_update` (Policy) —— **最关键**

    - 这是 PBDS 的灵魂。它告诉树：**“请在每个节点上额外维护一些信息（比如子树大小），以便我查询排名。”**

    - 不加这一行，它就是一个普通的 `std::set`。加上它，你才拥有 `order_of_key` 和 `find_by_order`。

#### 2. 核心成员函数用法

假设我们已经定义了 `ordered_set s;` 并插入了一些数据。

1. `order_of_key(value)` —— **查询排名**

    - **功能**：返回集合中**严格小于** `value` 的元素个数。

    - **复杂度**：$O(\log N)$。

    - **例子**：

        ```
        s.insert({10, 1});
        s.insert({20, 2});
        s.insert({30, 3});
        
        cout << s.order_of_key({20, 2}); // 输出 1 (只有 {10, 1} 比它小)
        cout << s.order_of_key({25, 0}); // 输出 2 ({10, 1} 和 {20, 2} 比它小)
        ```

2. `find_by_order(k)` —— **查询数值**

    - **功能**：返回指向排名为 `k` 的元素的**迭代器**（`k` 从 0 开始）。

    - **复杂度**：$O(\log N)$。

    - **例子**：

        ```
        auto it = s.find_by_order(0); 
        cout << it->first; // 输出 10 (排名第0的是最小的)
        ```

## [622.设计循环队列](https://leetcode.cn/problems/design-circular-queue/description/)

### 2026/4/21

使用一个数组，以及两个指针来模拟队列操作。

- 在循环队列中，`rear == front` 表示队列空，`(rear + 1) % sz == front` 表示队列满。
- 在循环队列中，rear的值可以小于front，所以表示队列满不能与空一样，因此有一个空间是被浪费的。

时间复杂度：$O(n)$，空间复杂度：$O(n)$。
