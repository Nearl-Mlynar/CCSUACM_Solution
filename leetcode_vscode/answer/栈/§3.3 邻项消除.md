## [1003.检查替换后的词是否有效](https://leetcode.cn/problems/check-if-word-is-valid-after-substitutions/description/)

### 2026/4/1

其实也是判断是否为合法括号序列问题，只不过这里有三个连续的段，可以直接维护连续段的长度

1. 如果 `cnt == 1` 并且 `x == 'b'` 那么 `stk.push(cnt + 1)`。
2. 如果 `cnt == 2` 并且 `x == 'c'` 那么直接弹出三个元素。
3. 如果上面都不满足，那么判断是否是新的一段 `y = x == 'a' ? 1 : 0`，把其加入栈中。
4. 最后判断栈长度是否为 $1$，因为最开始添加了哨兵节点 $0$。

时间复杂度：$O(n)$，空间复杂度：$O(n)$。

## [2216.美化数组的最少删除数](https://leetcode.cn/problems/minimum-deletions-to-make-array-beautiful/description/)

### 2026/4/1

贪心思路，对于每次删除其实直接删除掉不满足的数会更优，因为可以防止出现长连续一段，出现这种情况还是得要删这一段，不如就遇到就删除会更好，然后可以使用栈来维护前面的信息，使用栈中元素个数作为下标才是真实下标，最后如果长度不是偶数还要多删除一个，因此最后删除次数等于原长度减去栈中元素个数 + 是否为偶数：$nums.size() - stk.size() + (stk,size() % 2)$。

时间复杂度：$O(n)$，空间复杂度：$O(n)$。

## [1717.删除子字符串的最大得分](https://leetcode.cn/problems/maximum-score-from-removing-substrings/description/)

### 2026/4/1

根据题意可得有两种操作：

1. 删除 $ab$，获得 $x$ 的贡献。
2. 删除 $ba$，获得 $y$ 的贡献。

那么贪心的想，其实只有四种情况：

1. $abab$ 其实任意删除都是删除两次，那么记录贡献分别为 $max(g(ab) + g(ba), g(ab) * 2)$。
2. $baba$ 其实任意删除都是删除两次，那么记录贡献分别为 $max(g(ba) * 2, g(ab) + g(ba))$。
3. $aba$ 其实任意删除都是删除一次，那么记录贡献分别为 $max(g(ba), g(ab))$。
4. $bab$ 其实任意删除都是删除一次，那么记录贡献分别为 $max(g(ba), g(ab))$。

那么其实由上面的分析可得，其实只需要先尽量把所有贡献最大的删除删除掉，最后再遍历一遍累加另一类就行，可以使用栈来维护字符串前面的信息。

时间复杂度：$O(n)$，空间复杂度：$O(n)$。
