## [2536.子矩阵元素加 1](https://leetcode.cn/problems/increment-submatrices-by-one/description/)

### 2026/3/30

二维差分模板题，根据差分就是前缀和的逆运算可得，对于每一次查询都需要标记 $a_{i_1,j_1}, a_{i_1,j_2 +1}, a_{i_2 + 1, j_2}, a_{i_2 + 1, j_2 + 1}$，
$$
𝐷_{𝑥_1,𝑦_1} ← 𝐷_{𝑥_1,𝑦_1} + 𝑣,\\
𝐷_{𝑥_1,𝑦_2 + 1} ← 𝐷_{𝑥_1,𝑦_2 + 1} − 𝑣,\\
𝐷_{𝑥_2 + 1, 𝑦1} ← 𝐷_{𝑥_2 + 1, 𝑦_1} − 𝑣,\\
𝐷_{𝑥_2 + 1, 𝑦_2 + 1} ← 𝐷_{𝑥_2 + 1, 𝑦_2 + 1} + 𝑣.
$$
然后还原操作只需要逐维累加即可。

时间复杂度：$O(N^2)$，空间复杂度：$O(N^2)$。

## [2132.用邮票贴满网格图](https://leetcode.cn/problems/stamping-the-grid/description/)

### 2026/3/30

根据题目意思，也就是需要使用一个矩形去装满所有空格子，那么可以先找到所有满足没有占据的矩形，将所有满足的位置进行范围标记，那么如何维护这个信息，可以使用二维差分数组进行维护，如何快速查询矩形内部是否被占据，可以预处理一个二位前缀和数组，然后遍历所有右下角，找到所有满足的矩形并进行标记，最后遍历复原数组，如果每一个空格都被标记那么相当于满足，否则返回 $false$。

时间复杂度：$O(N^2)$，空间复杂度：$O(N^2)$。
