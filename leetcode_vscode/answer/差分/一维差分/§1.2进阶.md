## [2251.花期内花的数目](https://leetcode.cn/problems/number-of-flowers-in-full-bloom/description/)

### 2026/3/27

范围加考虑使用差分数组，观察到数组范围很大，因此需要使用 $map$ 来维护差分数组

但是困惑于不知道该如何复原，因为原查询数组是无序的，遂看灵神题解，豁然开朗

> [!IMPORTANT]
>
> 当需要对一个数组进行排序的时候，但是又不能直接排序从而打乱原来的顺序
>
> 可以使用一个 $idx$ 索引数组，将原数组的下标排序存入这个数组，这样子就获取到了顺序信息，但是也没有打乱原数组查询信息
>
> ```cpp
> vector<int> idx(n);
> iota(idx.begin(), idx.end(), 0);
> sort(idx.begin(), idx.end(), [&](int i, int j) {
>     return people[i] < people[j]; 
> });
> ```

通过这个操作之后，就可以按顺序使用前缀和复原差分数组，同时将信息按照原数组位置存储。

时间复杂度：$O(nlogn + mlogm)$，空间复杂度：$O(n + m)$。

## [1674.使数组互补的最少操作次数](https://leetcode.cn/problems/minimum-moves-to-make-array-complementary/description/)

### 2026/3/30

根据题意，对于每一对数的和的范围为 $[2, limit * 2] \ \&\& \ [min(a + b) + 1, limit + max(a + b)] \ \&\& \ [a + b, a + b + 1]$。

那么其实可以根据和的范围来统计修改次数，可以使用一维差分进行快速标记维护区间加减以及查询。

可以直接给最大范围$[2, limit * 2]$ 进行全体加，然后后续再根据范围减回来。

可以根据范围分为以下几类：

1. 对于范围 $[2, limit * 2]$，修改次数 $+2$。
2. 对于范围 $[min(a + b) + 1, limit + max(1, b) + 1]$，修改次数 $-1$。
3. 对于范围 $[a + b, a + b]$，修改次数 $-1$。

最后遍历差分数组，统计对于范围内和全为这个数的修改次数不断更新最小值 $mn = min(mn, pref)$。

时间复杂度：$O(limit * 2)$，空间复杂度：$O(limit * 2)$
