## [3756.连接非零数字并乘以其数字和 II](https://leetcode.cn/problems/concatenate-non-zero-digits-and-multiply-by-sum-ii/description/)

### 2026/3/23

先从不含 $0$ 的子串开始处理，如果使用两个前缀和数组一个存 $x$ 与 $sum$，

对于每一位更新可得，$pref[i] = (pref[i - 1] * 10 + s[i] - \ '0') % mod$， $prefsum[i] = prefsum[i - 1] + (s[i] - \ '0')$。
对于每一次查询可得，$ans = (pref[r] - pref[l] * 10^{(r - l + 1)}) * (prefsum[r]) - prefsum[l]$

那么对于含有 $0$ 的子串，其实观察式子可得：
对于每一位更新可得，$pref[i] = \begin{cases} pref[i - 1] * 10 + (s[i] - \ '0') & s[i] \neq\ '0' \\ pref[i - 1], & s[i] =\ '0'\end{cases}$，$prefsum[i] = prefsum[i - 1] + (s[i] - \ '0')$。
对于每一次查询可得，$ans = (pref[r] - pref[l] * 10^k) * (prefsum[r]) - prefsum[l]\ (这里 k 指的是[l,r]这个子串中的非 0 位数)$。
那么还需要一个前缀和来记录 $[l, r]$ 中不是 $0$ 的位数，$pref0[i] = pref0[i - 1] + (s[i] - \ '0' == 0 \ ? \ 0 : 1)$。

所以说最终对于 $[l,r]$ 的答案为 :

$ans = (pref[r] - pref[l - 1] * 10^{(pref0[r] - pref0[l - 1])} + mod) \ \%\ mod * (prefsum[r] - prefsum[l - 1] + mod) \ \%\ mod$。

$$

res2 = min(up2 + right2 - c2, up5 + right5 - c5) \\
res3 = min(down2 + left2 - c2, down5 + left5 - c5) \\
res4 = min(down2 + right2 - c2, down5 + right5 - c5) \\
mx = max({mx, res1, res2, res3, res4})
$$

暴力枚举 $x,y$ 时间复杂度 $O(N^2)$ 会超时，因此考虑枚举 $y, \lfloor \frac{x}{y} \rfloor$。

设 $d = \lfloor \frac{x}{y} \rfloor$，那么满足条件的 $x$ 的范围为 $d * y \le x < (d + 1) * y$ 的范围内。
对于答案的贡献为 $res += freq(x) * d * cnt[y]$.

那么如何求 $freq(x)$，首先用 $cnt[x]$ 统计元素 $x$ 在 $nums$ 中出现的次数。
记 $upper$ 为数组 $nums$ 中元素的最大值。 随后我们使用两重循环分别枚举 $y$ 和 $d$。其中枚举 $y$ 的循环的范围为 $[1, upper]$，枚举 $d$ 的循环的范围为 $[1, \lfloor \frac{upper}{y} \rfloor]$.
满足要求的 $x$ 的数量为： \[ \sum_{x = d \cdot y}^{\min\{(d+1)\cdot y - 1,\, upper\}} cnt[x] \]
